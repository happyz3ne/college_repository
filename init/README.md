## About This Section

This folder contains introductory materials, examples, and small practical assignments. It provides a quick overview of the course repository structure and helps prepare the development environment.

## What You Will Find Here

- basic Python examples;
- first classes and objects;
- short lesson notes;
- practical assignments for independent work.

## Quick Start

1. Make sure Python `3.11` or a compatible newer version is installed.
2. Clone the repository and open it in VS Code.
3. Run examples from the relevant topic folders.

```bash
python --version
```
