# Лабораторна робота №1

## Тема
Ознайомлення з Python. Робота зі змінними, форматованим виводом та модулем `datetime`.

## Мета роботи
Навчитися:
- створювати прості Python-скрипти;
- оголошувати змінні;
- використовувати рядкове форматування;
- виводити поточну дату та час;
- запускати програму через інтерпретатор Python.

## Опис завдання
У цій лабораторній роботі необхідно створити просту програму, яка:
- зберігає ім'я студента;
- зберігає місце проживання;
- виводить повідомлення з поточною датою та часом;
- демонструє базові можливості мови Python.

## Структура папки
- `code.py` — основний файл із програмою;
- `README.md` — опис лабораторної роботи.

## Вміст програми
Програма використовує:
- змінну `name` для зберігання імені;
- змінну `location` для зберігання міста;
- модуль `datetime` для отримання поточного часу;
- f-рядки для формування тексту виведення.

Приклад результату:

```python
Volodymyr start programming at 2026-09-24 12:34:56. Los Angeles is the best city!
```

## Як запустити програму
1. Відкрийте термінал або командний рядок.
2. Перейдіть до папки лабораторної роботи:

```bash
cd lab1
```

3. Запустіть файл:

```bash
python3 code.py
```

## Очікуваний результат
Після запуску в консолі з'явиться повідомлення з іменем, поточною датою та місцем проживання.
