## Тема: Ознайомлення з Python. Робота зі змінними, форматованим виводом та модулем `datetime`

### Мета роботи
Навчитися створювати прості Python-скрипти, оголошувати змінні, використовувати форматований вивід та працювати з датою та часом за допомогою модуля `datetime`.

### Завдання
1. Створити просту програму на Python.
2. Визначити змінні для імені студента та місця проживання.
3. Отримати поточну дату та час.
4. Вивести повідомлення у консоль за допомогою f-рядка.
5. Зберегти результат у репозиторії у вигляді звіту.

### Виконання роботи
Для виконання лабораторної роботи було створено файл `code.py`, у якому зберігаються значення імені та місця проживання. Далі використано модуль `datetime` для отримання поточного часу і побудови повідомлення за допомогою форматованого рядка.

Код програми:

```python
from datetime import datetime
name = "Volodymyr"
location = "Los Angeles"

print(f"{name} start programming at {datetime.now()}. {location} is the best city!")
```

Після запуску програми в консоль виводиться повідомлення такого формату:

```python
Volodymyr start programming at 2026-09-24 12:34:56. Los Angeles is the best city!
```
